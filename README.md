## Adding the assets

Place the existing `assets` folder beside these files:

```text
site folder/
├── assets/
├── index.html
├── post-acceptance.html
├── …
└── site-search-index.js
```

The package intentionally links O-Week to the official student O-Week website rather than carrying a separate, replicated O-Week page.
